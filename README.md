# European Football Analytics Shiny Dashboard

**Live app:** https://prirncekrampah.shinyapps.io/european-football-analytics/

A data visualization school project built with R Shiny that explores European football (soccer) data across 11 leagues and 8 seasons (2008/2009 to 2015/2016). The dashboard provides interactive visualizations for comparing team performance, player ratings, and skill attributes using match and FIFA player data.

## Visualizations

The app is organized into four tabs:

1. **Player Improvement**, Scatter plot of player ratings by age and position, with lasso/box selection to view individual rating trajectories over time.
2. **League Performance**, Stacked bar charts showing win/draw/loss rates across teams in a league, with the ability to compare head-to-head records against a specific team.
3. **Team Statistics**, Bubble chart plotting average goals scored vs. conceded, with bubble size representing possession rate and team logos overlaid.
4. **Player Comparison**, Radar chart comparing up to three players across five FIFA skill attributes (short passing, long passing, stamina, crossing, ball control).

## Data Setup

The app loads a pre-processed `data.RData` file. If you need to regenerate it from the raw CSVs in `datasets/`, run the initialization script first:

```r
source("initialize_data.R")
```

This reads the CSV files, joins match/player/possession data, computes player improvement metrics, and saves the result to `data.RData`.

## Running the App

From the project directory, start the app with:

```r
shiny::runApp()
```

Or from the terminal:

```bash
Rscript -e "shiny::runApp('.')"
```

The app will open in your default browser at `http://127.0.0.1:PORT`.
